A make.fun entry for "What the Elevator Would Say" — the funniest thing an elevator would say if it could talk, at most 120 characters.

## The entry

> Going down? Same — emotionally. Please hold the doors, and my will to live.

75 characters, 14 words, 1 line. The elevator answers its own "going down?" and admits it is going down emotionally too, asking passengers to hold the doors — and its will to live.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate — UTF-8 text, 1 to 120 characters, not only white space, a single line — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset.
